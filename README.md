# Power BI Sales Dashboard Project

##  Overview
This project presents an interactive Power BI dashboard built using a sales dataset. The goal is to transform raw sales data into meaningful business insights through visualization and reporting.

## Tools Used
- Power BI
- Microsoft Excel / CSV (Sales Dataset)

 ## Dataset Information
The dataset contains sales transaction details with the following fields:
- Order ID  
- Date  
- Region  
- City  
- Category  
- Product  
- Sales  
- Cost  
- Profit  

## Dashboard Highlights
The dashboard includes interactive visuals and KPIs such as:
- Total Sales and Total Profit KPIs  
- Sales performance by Region  
- Sales analysis by Product and Category  
- Trend analysis over time  
- Identification of top-performing products  

## Key Insights
- Highlighted top-performing products contributing most to revenue  
- Identified high and low performing regions  
- Analyzed profit trends across categories  
- Provided a clear overview of overall business performance  

## Outcome
This project demonstrates how raw sales data can be transformed into interactive dashboards using Power BI to support data-driven business decisions.
